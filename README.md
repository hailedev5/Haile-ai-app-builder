## 🌟 Overview

**Haile AI** is engineered from the ground up for programmers, creators, scientists, and systems thinkers who need more than a generic chatbot. It provides a lightning-fast, high-precision developer cockpit equipped with:

1. **A Universal 52-Language Offline Compiler & VM Studio** (C, C++, Rust, Go, Python, Zig, Lua, SQLite, Ruby, Brainfuck, WASM, and 40+ more).
2. **Interactive Live Artifacts Canvas** for instant HTML5, React, Markdown, and SVG live preview and version tracking.
3. **Deep Cognitive Reasoning** with Gemini 2.5 Pro and Flash with expandable Thinking Mode breakdown.
4. **Interactive Mermaid.js Diagramming** for automatic architecture flowcharts, sequence graphs, and class diagrams.
5. **Creative Studio** with Google Imagen 3 (`imagen-3.0-generate-002`) and multi-aspect-ratio rendering.
6. **Bilingual Neural Voice Synthesis (TTS)** and continuous Speech Recognition.
7. **Zero-Telemetry, Privacy-Respecting Architecture** with local backup, restore, and offline-capable AST runtimes.

> [!TIP]
> **Instant Hotkey**: Press <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> (or <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd>) anywhere in the app to immediately summon the **52-Language Offline Compiler Studio**!

```
                        └──────────────────┬───────────────────┘ └──────────────────┬───────────────────┘
```

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Node.js** v18.0.0 or higher (v20+ recommended)
- **npm** or **pnpm**
- **Google Gemini API Key** (Get yours free at [Google AI Studio](https://aistudio.google.com/))

### 2. Clone the Repository
```bash
git clone https://github.com/hailedev5/haile-ai-app-builder.git
cd haile-ai-app-builder
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Set Up Environment Variables
Create a `.env` file in the project root:
```env
# Gemini API Key (Required for AI generation, Imagen 3, and reasoning)
GEMINI_API_KEY="your-gemini-api-key-here"

# Application Port (Defaults to 3000)
PORT=3000
```

### 5. Launch Development Server
```bash
npm run dev
```

Your app will immediately be live at:
👉 **`http://localhost:3000`**

### 6. Build for Production
```bash
npm run build
npm start
```

The built-in backend proxy exposes clean, authenticated routes for code execution and AI processing:

### `POST /api/compile`
Executes code across 52+ programming languages in an isolated environment.
```json
// Request Body
{
  "language": "python",
```

## 🛡️ Security, Privacy & Isolation

- **Client-Side Data Storage**: All your messages, system instructions, and code history stay directly in your browser's `localStorage`.
- **Zero Third-Party Trackers**: No Google Analytics, no Facebook Pixels, no behavioral trackers.
- **Sandboxed Execution**: Backend code runs through timed, isolated child processes with memory and CPU boundaries.
- **Private API Key Delivery**: Your `GEMINI_API_KEY` is securely read on the server side and never exposed in client bundles.
